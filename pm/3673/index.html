LPT lathund

Syfte och omfattning

Intyg om psykiatrisk vård ogiltigförklaras ofta pga. fel i nedanstående viktiga formalia ej ifyllts korrekt. Dokumentet syftar till att de juridiskt nödvändiga punkterna fylls i korrekt vid utfärdande av vårdintyg. Rutinen vänder sig till samtliga läkare som träffar patienter som bedöms ha behov av psykiatrisk tvångsvård. Se HSLF-FS 2020:87 Socialstyrelsens föreskrifter om ändring i föreskrifterna (HSLF-FS 2018:54) om att utfärda intyg i hälso- och sjukvården - Socialstyrelsen

Beskrivning

Rätt blankett krävs för att vårdintyget ska gälla:

  • För legitimerade läkare som ej tjänstgör inom psykiatrin är det i stort sett alltid vårdintyget, blanketten §3/4 som gäller.

Det finns två ytterligare vårdintyg:

  • Ett används för patienter som vårdas på psykiatrisk avdelning enligt HSL, så kallad konvertering (§11 LPT).
  • Ett annat för patienter som ska vårdas enligt Rättspsykiatrisk vård - LRV vilket används för häktade, anhållna (men ej gripna) och personer intagna på, eller som ska föras till kriminalvård (ex. slutet ungdomshem).
  • Ange hur man styrkt patientens identitet; id-handling, pass, personlig kännedom, polis etc. Om identitet inte går att styrka bör polis kontaktas för identifiering gentemot passarkiv helst men om det inte går, skriv det - lämna inte utrymmet tomt och skriv ett tydligt signalement tex i rutan för status.
  • Rutan för svensk legitimation måste vara ifylld.
  • Blanketten måste vara signerad för att vara giltig

Allmänt om ifyllnad

Sidan 1 Status:

Det är dina observationer som ligger till grund för vårdintyget såväl psykiskt status som somatiskt. Observera dock att en somatisk undersökning inte är tvingande men det kan vara nog så viktigt att påtala observerbara fynd.

Sidan 2 Anamnes:

Alla rutor för anamnes behöver inte vara ifyllda på sidan 2. Huvudsyftet är förstås att det ska finnas information för att kunna styrka din bedömning om att de 3 kriterierna för LPT vård är uppfyllda:

  • Det föreligger en allvarlig psykisk störning
  • Det föreligger ett oundgängligt behov av specialistpsykiatrisk vård

Sida 2 av 3

  • Patienten motsätter sig psykiatrisk vård och behandling eller inte kan ta grundat beslut härom

Sidan 3 och 4 Bedömning:

Obligatoriskt att fylla din bedömning på dessa sidor kring att de 3 kriterierna är uppfyllda.

Allvarlig psykisk störning (APS)

Huvudprincipen avseende APS juridiskt handlar om störd verklighetsuppfattning, där psykos men naturligtvis även andra tillstånd av psykosnära art kan inkluderas vilket kan innefatta djup depression med suicidalitet, allvarlig personlighetsstörning med uttalad impulskontrollproblematik som under pågående kris kan få sviktande verklighetsuppfattning och få uttalade självskade-/suicidala impulser, konfusioner/delirium med hallucinationer/vanföreställningar men också allvarlig anorexi med risk för metabola störningar på centrala kroppsfunktioner. Se vidare ifyllnadsstöd på Socialstyrelsens hemsida.

Oundgängligt behov av kvalificerad psykiatrisk heldygnsvård

Oftast den punkt som vållar mest besvär att formulera. Men det handlar om att personen inte i nuläge kan vårdas i psykiatrisk öppenvård tex pga. hög suicidrisk, oförmåga att reda för egen person vid tex psykossjukdom men här kan också faran för patientens liv eller omgivning bidra såsom vid aggressivitet/våldsamhet.

Inställning till erbjuden vård

Observera att patienten inte måste vägra vård, det kan handla om att patienten inte är kapabel att ta ställning till sitt vårdbehov, eller erfarenhetsmässigt säger sig acceptera vård initialt för att snart skriva ut sig.

Allmänt om LPT vård

Syftet med den psykiatriska tvångsvården är att under en period när patienten till följd av sitt tillstånd saknar förmåga att se till sitt eget bästa ge patienten den psykiatriska vård som behövs. Målet är att behandla den psykiatriska allvarliga störningen så att patienten kan återfå sjukdomsinsikt/återfå förmåga till grundat ställningstagande och motiveras till fortsatt frivillig vård. Det är alltså psykiatrisk behandling/behandling som kan häva APS som kan ges enligt LPT. Om det handlar om behandling för kroppslig sjukdom blir det vanligen svårare, det krävs mer eller mindre vital indikation och det blir oftast en diskussion mellan specialistläkare inom psykiatri samt berörd somatisk enhet. Här måste man också ta hänsyn till andra aspekter såsom åberopande av nöd men också presumtivt samtycke samt etiska aspekter. När vårdas patienten enligt LPT? Det vill säga när kan tvångsåtgärder vara aktuella? När vårdintyg är utfärdat innebär det INTE att patienten ”är på LPT” och att tvångsåtgärder kan ske! Det är bara psykiatrins bakjour (eller annan specialistläkare från psykiatrin med Chefsöverläkardelegation) som kan besluta om tvångsåtgärd. Se LPT tvångsvård somatiskvård
