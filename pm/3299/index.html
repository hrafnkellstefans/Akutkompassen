Viktig information som avser rekommendationerna

  • Doseringsanvisningarna avser vuxna. För dosering till barn, se ePed (om du använder en dator från Akademiska sjukhuset) eller eped.se

•

•

  • Med pc-allergi menas typ 1-allergi mot betalaktamantibiotika (urticaria, anafylaxi, bronkospasm) om ej annat anges. För mer information, se separat PM Korsallergi betalaktamantibiotika

•

•

  • Relevanta odlingar ska alltid tas före antibiotikainsättning samt vid terapisvikt utifrån misstänkt infektionsfokus. Odla aerobt + anaerobt vid incision av abscess. Alltid blododling x 2 före insättning av intravenös antibiotika samt vid feber eller anamnes på feber.

•

  • Vid övervikt BMI>30 kg/m2 kan justering av antibiotikadosen vara nödvändig, se separat PM Antibiotikadosering vid övervikt (BMI > 30)

•

  • Vid sepsis/septisk chock ges en extra dos betalaktamantibiotika efter halva intervallet mellan första och andra dosen på grund av ökad distributionsvolym.

Öron

Akut otit med komplikation – t ex mastoidit, labyrintit, facialispares Bakterier: Vuxna: Pneumokocker, β-hemolyserande streptokocker grupp A, ibland Haemophilus influenzae.

Barn: Pneumokocker, Haemophilus influenzae. Ovanligt med β-hemolyserande streptokocker men det kan förekomma.

Sida 3 av 9

Behandling: Cefotaxim 1-2 g x 3 iv. Cefotaxim bör alltid väljas vid misstänkt eller påvisad Haemophilus influenzae. Efter odlingssvar eller om mindre påverkad patient kan ampicillin 2 g x 3 iv eller bensylpenicillin 1-3 g x 3 iv ges (högre dosen om svåråtkomlig lokal).

Vid pc-allergi: Klindamycin 600 mg x 3 iv (om pneumokocker eller streptokocker, ej aktivitet mot Haemophilus influenzae). Alternativt ges Eusaprim 10 ml x 2 iv. Vid mer påverkad patient ges moxifloxacin 400 mg x 1 iv.

Peroral uppföljning: Amoxicillin 500 – 750 mg x 3 po (vid misstänkt eller påvisad Haemophilus influenzae ges den högre dosen). Om odling visar β-laktamasproducerande Haemophilus influenzae ges amoxicillin/klavulansyra 875mg x 3 po. Vid kromosomalt medierad resistens behandling efter resistensbesked.

Peroral uppföljning vid pc-allergi: Klindamycin 300 mg x 3 po (om pneumokocker eller streptokocker, ej aktivitet mot Haemophilus influenzae) alternativt Eusaprim forte/Bactrim forte 1 x 2 po (beroende på odlingssvar).

Kronisk otit – långdraget förlopp eller allmänpåverkan/annan komplikation Bakterier: Anaeroba grampositiva kocker, S.aureus, E.coli, Proteus, P. aeruginosa.

Behandling: Piperacillin/tazobaktam 4 g x 3-4 iv (4 g x 4 vid misstänkt eller påvisad Pseudomonas).

Peroral behandling/uppföljning: Peroral behandling grundas på odlings- och resistensbesked. Om ren pseudomonasinfektion är ciprofloxacin 750 mg x 2 po ett alternativ. Observera att ciprofloxacin i injektionsform ej tillför någon ytterligare terapieffekt jämfört med tabletter.

Kontakta infektionskonsult vid tveksamhet om terapival eller vid pc-allergi.

Malign extern otit

Bakterier: P. aeruginosa, ibland även S. aureus.

Behandling: Piperacillin/tazobaktam 4 g x 3-4 iv (4 g x 4 vid misstänkt eller påvisad Pseudomonas) alternativt ceftazidim 2 g x 3 iv (om odlingssvar som visar Pseudomonas).

Peroral behandling/uppföljning: Peroralt alternativ vid Pseudomonas är ciprofloxacin 750 mg x 2 po. Observera att ciprofloxacinresistenta Pseudomonasstammar blivit allt vanligare. Vid S. aureus ges flukloxacillin 1 g x 3 eller klindamycin 300 mg x 3 po. Överväg lokalbehandling med ciprofloxacin (Ciloxan) och/eller Acid Acet 2%.

Sida 4 av 9

Behandlingstidens längd är beroende på status.

Kontakta infektionskonsult vid tveksamhet om terapival eller vid pc-allergi.

Perichondrit

Bakterier: S. aureus, ibland även P. aeruginosa.

Behandling: Kloxacillin 2 g x 3-4 iv alt piperacillin/tazobaktam 4 g x 3-4 iv.

Peroral uppföljning: Flukloxacillin 1 g x 3 po alt ciprofloxacin 750 mg x 2 po (efter odlingssvar). Alsolspritomläggning.

Pc-allergi: Klindamycin 600 mg x 3 iv eller klindamycin 300 mg x 3 po. Vid påvisad eller misstänkt Pseudomonas rådgör med infektionskonsult.

Näsa

Näsfurunkel

Bakterier: S. aureus.

Behandling: Kloxacillin 2 g x 3 iv.

Peroral uppföljning: Flukloxacillin 1g x 3 po.

Pc-allergi: Klindamycin 600 mg x 3 iv eller klindamycin 300 mg x 3 po.

Fucidinsalva rekommenderas först efter svar på odling då det inte är ovanligt med fucidin-resistens hos S. aureus.

Septumabscess

Bakterier: S. aureus.

Behandling: Kloxacillin 2 g x 3 iv

Peroral uppföljning: Flukloxacillin 1 g x 3 po.

Pc-allergi: Klindamycin 600 mg x 3 iv eller klindamycin 300 mg x 3 po. Vid resistens kan Linezolid 600 mg x 2 po vara ett alternativ. Observera risk för interaktioner och biverkningar, kontakt med infektionskonsult rekommenderas.

Sida 5 av 9

Munhåla och svalg

Tandabscess och munbottenflegmone/abscess

Bakterier: Anaeroba streptokocker, fusobakterier.

Behandling: Bensylpenicillin 1-3 g x 3 iv (högre dosen om svåråtkomlig lokal). Beroende på svårighetsgrad kan man vid behov lägga till metronidazol 1,5 g x 1 iv dag 1, därefter 1 g x 1 iv alt metronidazol 400 mg x 3 po (om patienten kan ta tabletter). Vid allvarligt sjuk patient eller immunsuppression ges piperacillin/tazobaktam 4 g x (3-)4 iv.

Peroral uppföljning: Fenoximetylpenicillin 1 g x 3 po (+/- metronidazol 400 mg x 3 po). Alternativt klindamycin 300 mg x 3 po.

Pc-allergi: Klindamycin 600 mg x 3 iv. Vid kritiskt sjuk patient kontakta infektionskonsult.

Septisk parotit

Bakterier: S. aureus, munhåleflora.

Behandling: Kloxacillin 2 g x 3 iv + metronidazol 1,5 g x 1 iv dag 1, därefter 1 g x 1 iv eller metronidazol 400 mg x 3 po (om patienten kan ta tabletter). Alternativt klindamycin 600 mg x 3 iv.

Peroral uppföljning: Flukloxacillin 1 g x 3 po (eventuellt i kombination med metronidazol beroende på odlingssvar) alternativt klindamycin 300 mg x 3 po.

Pc-allergi: Klindamycin 600 mg x 3 iv.

Tonsillit

Bakterier: β-hemolyserande streptokocker grupp A.

Behandling: Vid allvarlig infektion: Bensylpenicillin 1 g x 3 iv, annars fenoximetylpenicillin 1 g x 3 po.

Pc-allergi: Cefadroxil 0,5-1 g x 2 po (ej vid typ 1 allergi mot pc). Klindamycin 300 mg x 3 po (vid typ 1 allergi).

Vid recidiv: Klindamycin alternativt cefadroxil i samma doser som ovan.

Sida 6 av 9

Peritonsillit

Bakterier: Anaeroba streptokocker, β- hemolyserande streptokocker, fusobakterier, Eikinella corrodens.

Behandling: Bensylpenicillin 3 g x 3 iv alternativt fenoximetylpenicillin 2 g x 3 po. Dosen kan sänkas efter några dygn postop och klar klinisk förbättring.

Pc-allergi: Klindamycin 600 mg x 3 iv alternativt klindamycin 300 mg x 3 po.

Parafaryngeal/retrofaryngeal abscess

Bakterier: Anaerober, streptokocker, S aureus, pneumokocker.

Behandling: Cefotaxim 2 g x 3 iv kombinerat med metronidazol 1,5 g x 1 iv dag 1, därefter 1 g x 1 iv. Vid allvarligt sjuk patient eller immunsuppression ges piperacillin/tazobaktam 4 g x 3-4 iv.

Pc-allergi: Klindamycin 600 mg x 3 iv. Vid kritiskt sjuk patient kontakta infektionskonsult.

Lemièrres syndrom

Bakterier: Fusobacterium necrophorum (andra fusobakterier eller bacteroidesarter).

Behandling: Metronidazol 1,5 g x 1 iv dag 1, därefter 1 g x 1 iv (400 mg x 3 po när patienten kan ta tabletter). Metronidazol ges initialt i kombination med bensylpenicillin 3 g x 3 iv eller cefotaxim 2 g x 3 iv.

Peroral uppföljning: Kontakta infektionskonsult.

Pc-allergi: Kombinera initialt metronidazol med klindamycin 600 mg x 3 iv.

Epiglottit

Bakterier: H. influenzae, pneumokocker, β-hemolyserande streptokocker, E. coli, sekundärinfekterad valleculacysta med S. aureus.

Behandling: Cefotaxim 2 g x 3 iv.

Peroral uppföljning: Amoxicillin 500 – 750 mg x 3 po (vid misstänkt eller påvisad Haemophilus influenzae ges den högre dosen). Om odling visar β-laktamasproducerande Haemophilus influenzae ges amoxicillin/klavulansyra 875mg x 3 po. Vid kromosomalt medierad resistens behandling efter resistensbesked.

Pc-allergi: Kontakta infektionskonsult.

Sida 7 av 9

Ansikte och hals

Erysipelas

Bakterier: β- hemolyserande streptokocker grupp A. Om sår kan det någon gång vara blandinfektion med S. aureus.

Behandling: Bensylpenicillin 1-3 g x 3 iv. Vid stark misstanke om samtidig S. aureus infektion ges istället kloxacillin 2 g x 3 iv.

Peroral uppföljning: Fenoximetylpenicillin 1 g x 3 po eller om S. aureus flukloxacillin 1 g x 3 po.

Pc-allergi: Klindamycin 600 mg x 3 iv eller klindamycin 300 mg x 3 po.

Impetigo

Bakterier: β- hemolyserande streptokocker, S. aureus.

Behandling: Rengöring med tvål och vatten, alternativt klorhexidin- eller alsol- lösning, Mikrocidkräm 1 %. Vid utbredda förändringar och bullös impetigo rekommenderas flukloxacillin 1 g x 3 po.

Fucidinsalva rekommenderas efter odlingssvar om lokalbehandling ej haft effekt.

Misstanke om nekrotiserande fasciit

Handläggning: se separat PM Allvarliga mjukdelsinfektioner i DocPlus. Tag alltid kontakt med infektionsjour/bakjour samt plastikkirurgjour!

Bakterier: β- hemolyserande streptokocker grupp A, S. aureus, gramnegativa bakterier, anaerober.

Behandling: Bensylpenicillin 3 g x 3-4 iv om positivt snabbtest för streptokocker, annars imipenem/cilastatin 1 g x 3-4. I båda fallen ska behandlingen alltid kombineras med klindamycin 600 mg x 3 iv.

Pc-allergi: Kontakta infektionskonsult.

Lymfadenit på halsen med begynnande abscessbildning Bakterier: β- hemolyserande streptokocker grupp A, S. aureus. Mykobakterier kan förekomma.

Sida 8 av 9

Behandling: Bensylpenicillin 1-3 g x 3 iv. Om misstanke om S. aureus ges kloxacillin 2 g x 3-4 iv.

Pc-allergi: Klindamycin 600 mg x 3 iv.

Esofagus

Esofagusperforation

Behandling: Piperacillin/tazobactam 4 g x 3-4 iv eller imipenem/cilastatin 1 g x 3 iv.

Pc-allergi: Kontakta infektionskonsult.

Sinus

Maxillar/frontalsinuit

Bakterier: Pneumokocker, H. influenzae.

Behandling: Cefotaxim 1-2 g x 3 iv (högre dosen om svåråtkomlig lokal). Vid lindrigare sinuit ges fenoximetylpenicillin 2 g x 3 po i 10 dagar.

Vid terapisvikt: Överväg spolning och byte till amoxicillin 750 mg x 3 po (ta odling på spolutbyte och/eller i nasofarynx). Om svikt även på detta vid negativ odling ges doxycyklin 100 mg 2 x 1 po i en dag, därefter 1 x 1 i 9 dagar (annars behandling efter odlingssvar).

Pc-allergi: Eusaprim 10 ml x 2 iv eller Eusaprim forte/Bactrim forte 1 x 2 po eller Doxycyklin 100 mg 2 x 1 i en dag, därefter 1 x 1 po.

Ethmoidit

Bakterier: Pneumokocker, H. influenzae.

Behandling: Cefotaxim 1-2 g x 3 iv.

Peroral uppföljning: Amoxicillin 500 – 750 mg x 3 po (vid misstänkt eller påvisad Haemophilus influenzae ges den högre dosen). Om odling visar β-laktamasproducerande Haemophilus influenzae ges amoxicillin/klavulansyra 875mg x 3 eller Eusaprim forte/Bactrim forte 1 x 2 po. Vid kromosomalt medierad resistens behandling efter resistensbesked.

Pc-allergi: Kontakta infektionskonsult.
