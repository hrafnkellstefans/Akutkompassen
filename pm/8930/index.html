Introduktion

Infektioner i bukhålan uppstår oftast genom perforation av GI-kanalen. Noggrann diagnostik för att kartlägga var perforationen uppstått är av värde för adekvat behandling. Innan terapi inleds bör alltid adekvata odlingar säkras. Som regel krävs bred täckning av grampositiva, gramnegativa (till exempel E. coli, Klebsiella spp) och anaeroba bakterier (Bacteroides fragilis). På grund av resistensutvecklingen hos flera tarmpatogener, till exempel ESBL-producerande tarmbakterier och vancomycinresistenta enterokocker (VRE), bör användandet av cefalosporiner och kinoloner begränsas.

I vissa fall kan antibiotikabehandling undvikas helt som vid okomplicerad divertikulit, eller kombineras/ersättas av kirurgisk behandling som vid kolecystit. Korta behandlingstider är eftersträvansvärt. Vid okomplicerade infektioner och med source control 4–5 dagar, vid sepsis och septisk chock är 7 dagar i regel adekvat. Längre behandlingstid endast vid bristande/ofullständig source control.

Överviktiga patienter

Vid behandling av patienter med övervikt krävs ibland en högre dosering, särskilt vid allvarliga infektioner. Det gäller till exempel klindamycin, ciprofloxacin samt tigecyklin. Se vidare DocPlus-dokument Antibiotikadosering vid övervikt.

Sida 2 av 4

Kolecystit/kolangit

De flesta patienter med kolecystit kan ofta behandlas utan antibiotika. Akut eller subakut kolecystektomi är ofta att föredra. Vid gangränös/perforerad kolecystit ges antibiotika. Antibiotika ges även vid samtidig sepsis, peritonit samt vid tecken på kolangit. Vid kolangit bör man överväga att säkerställa avflödet av gallvägarna.

Pankreatit

Antibiotikabehandling bör inte användas utan reserveras till infektionskomplikationer såsom abscess, infekterad nekros eller septisk chock. Odling ska säkras innan antibiotika sätts in.

Appendicit

Antibiotika rekommenderas endast vid perforerad appendicit med peritonit eller abscess, och bör täcka både aeroba och anaeroba bakterier. Vid okomplicerat förlopp ges numera ceftriaxon 2 g x 1 iv + T metronidazol 400 mg x 3 i 3 dagar. I övriga fall, se tabell nedan. Vid abscess >5 cm i diameter, eller behandlingssvikt, kan ultraljudsledd perkutan dränering vara aktuell.

Divertikulit

Vid okomplicerad inflammation utan allmänpåverkan hos i övrigt immunkompetenta, där klinik och/eller DT buk inte talar för perforation eller abscess inleds behandling med tarmvila utan antibiotika. Vid uttalad inflammation såsom vid hög feber, allmänpåverkan och peritonit eller vid utebliven förbättring/försämring efter 48–72 timmar rekommenderas antibiotika. Vid abscess överväg dränage, samt vid perforation ut i fri bukhåla, bred antibiotikabehandling samt operation.

Bukabscess

Perkutant eller kirurgiskt dränage är mycket viktigt för läkningen av en intraabdominal abscess och kan räcka som behandling om infektionen är avkapslad. Blododling och odling från abscess är viktigt och bör om möjligt föregå antibiotisk behandling.
